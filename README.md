# Talynor

Talynor is a visual learning and personal knowledge platform where users build interconnected knowledge maps, organize learning content, and track their studies.

**Current status:** foundation and planning. This repository contains project documentation and operating rules for future coding agents. No application, solution, database, or infrastructure has been created.
