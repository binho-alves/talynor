# Talynor

Talynor is a visual learning and personal knowledge platform where users build interconnected knowledge maps, organize learning content, and track their studies.

**Current status:** foundation, Phase 1 — SPIKE-001, and Phase 2 — Solution and Application Skeleton are completed and approved. VS-001 — Read-only Knowledge Graph Vertical Slice is implemented and pending review as a validation slice between Phase 2 and Phase 3. React reads the two demonstration maps through the .NET API and adapts the independent HTTP contract to XYFlow. No persistence or identity is implemented; progress and study time remain demonstration values. Phase 3 remains Identity and Workspace and has not started.

See [the frontend spike](src/frontend/talynor-web/README.md) for local commands, interactions, limitations, and React learning notes.
